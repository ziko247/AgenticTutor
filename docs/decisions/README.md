# Décisions de conception

Aucune décision technique définitive n'est encore enregistrée. Les propositions du cahier des charges restent à valider.

Créer un fichier `NNNN-short-title.md` pour un choix significatif en utilisant `TEMPLATE.md`. Indiquer son statut : proposé, accepté ou remplacé. Conserver les anciennes décisions et lier leur remplacement.

Une décision proposée ne doit pas être présentée ailleurs comme validée.
