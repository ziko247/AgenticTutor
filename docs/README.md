# Documentation du projet

Commencer par le README racine, le cahier des charges et `AGENTS.md`.

- `architecture/` : frontières techniques, flux et futures conceptions de données/API.
- `decisions/` : décisions validées et leurs raisons.
- `design/` : futures maquettes et parcours.
- `guides/` : futurs guides d'installation, d'utilisation et de gestion.
- `report/` : rapport, résultats relus et matériel de soutenance.

Le cahier des charges reste à la racine pour préserver les liens existants. Les dossiers vides ne constituent pas des livrables achevés.
