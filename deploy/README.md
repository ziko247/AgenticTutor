# Déploiement et exploitation

Emplacement réservé aux futurs fichiers de conteneurisation et configurations d'environnement. Aucun Dockerfile, compose ou déploiement n'est encore fourni.

Après validation de l'hébergement, documenter les services frontend/backend/base/index, les secrets côté serveur, les volumes persistants, les contrôles de santé, les quotas, les sauvegardes et la restauration. Le guide de lancement reproductible ira dans `docs/guides/`.

Utiliser des configurations d'exemple sans credentials ; ne pas versionner les fichiers locaux contenant des secrets.
