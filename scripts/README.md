# Scripts de développement et de préparation

Emplacement réservé aux futurs outils de préparation de contenu, validation de formats et création de données synthétiques. Aucun script n'est fourni à ce stade.

Documenter pour chaque outil ses arguments, entrées, sorties, prérequis et effets. Les scripts doivent distinguer explicitement les contenus d'apprentissage des lots d'évaluation et éviter les suppressions ou écrasements implicites.
