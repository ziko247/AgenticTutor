# Tests transversaux

- `e2e/` : parcours complets navigateur → API, dont diagnostic, séance et reprise.
- `fixtures/` : petites données synthétiques partageables.

Les tests unitaires et d'intégration backend vont dans `backend/tests/`. Les tests de l'interface vont dans `frontend/tests/`. L'évaluation de la qualité IA et pédagogique va dans `evaluation/`.

Aucun runner ni test n'est encore implémenté. Ajouter les commandes ici lorsqu'elles sont installées et vérifiées. Ne jamais utiliser de vrais comptes étudiants ou de secrets dans les fixtures.
